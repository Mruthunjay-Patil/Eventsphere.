EVENTSPHERE — UPDATED PROJECT

This archive includes the requested authentication, payment visibility, email notifications, admin, vendor navigation, support-ticket, category-editing, and Render deployment changes.

LOCAL DEVELOPMENT
1. Extract this folder and open it in VS Code.
2. Copy .env.example to .env and configure MongoDB Atlas, JWT_SECRET, admin credentials, SMTP, and payment test keys.
3. npm install
4. Terminal 1: npm run dev:main
5. Terminal 2: npm run dev:admin
6. Main app: http://localhost:3000
7. Admin portal: http://localhost:3001

GOOGLE LOGIN
Set GOOGLE_CLIENT_ID and VITE_GOOGLE_CLIENT_ID to the same Google OAuth Web Client ID. Add the website origin to Authorized JavaScript origins in Google Cloud Console. Never put a Google client secret, JWT secret, or gateway secret in frontend code.

RENDER DEPLOYMENT
A render.yaml Blueprint is included. Push to a private GitHub repository, create a Blueprint in Render, and set every sync:false variable. The production main service serves the admin app at /admin.html. Set APP_URL and APP_BASE_URL to the public Render URL and configure the Stripe webhook at /api/payments/webhook.

SECURITY
- .env is ignored by git and is not included in this ZIP.
- Rotate any credentials that have been shared in chat.
- Test Stripe and Razorpay in test mode before any live use.
- Admin credentials must be strong and unique.
